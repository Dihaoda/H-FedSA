# CIFAR-10 IID clean RFA formal evidence

This directory preserves the resolved configuration and generated run summary
for each preregistered seed (`2026`--`2030`). The shared manifest is
`configs/paper/cifar10_iid_clean_rfa.yaml`; all runs declared source revision
`74fbaaa2c93f2f1f17b4ea4748826db3319f7e24`, used real CIFAR-10/CIFAR-10-C
data, and completed 250 communication rounds.

The final seed errors were `15.19%`, `15.00%`, `15.27%`, `15.39%`, and
`14.87%`. Their mean and sample standard deviation are
`15.144 +/- 0.209%`, compared with the paper target `15.2 +/- 0.3%` (mean gap
`-0.056` percentage points). The published machine-readable aggregate is
`results/published/cifar10_iid_clean_rfa_5seeds.json`.

The evidence files are generated artifacts retained for auditability. The
manifest remains the canonical configuration for reruns.
